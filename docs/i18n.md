# i18n Kuizen (dwibahasa)

Dua bahasa sahaja: **English (lalai, Standard English)** dan **Bahasa Melayu**
(baku Malaysia). Satu skrin tidak boleh mencampurkan dua bahasa. Pilihan
bahasa milik pengguna, disimpan dalam kuki `kz_lang`.

## Fail

| Fail | Peranan |
|---|---|
| `src/lib/i18n/kamus/en.ts` | Kamus English. SUMBER JENIS: semua kunci ditakrifkan di sini dahulu. |
| `src/lib/i18n/kamus/ms.ts` | Kamus BM. `type Kamus = typeof en` memaksa setiap kunci English wujud di sini. |
| `src/lib/i18n/index.ts` | `Bahasa`, `BAHASA_LALAI`, `NAMA_KUKI`, `sahBahasa`, `terjemah`, `terjemahBilangan`, `KunciKamus`. |
| `src/lib/i18n/pelayan.ts` | `bahasaPelayan()` untuk komponen pelayan (layout, metadata). |
| `src/lib/i18n/BahasaProvider.tsx` | Konteks klien `{ bahasa, tukarBahasa, t }`, `useBahasa()`. |
| `src/components/PemilihBahasa.tsx` | Butang "EN \| BM". |

## Cara memilih bahasa dalam kod

### Komponen klien (kebanyakan halaman)

```tsx
const { t, bahasa } = useBahasa();
<h1>{t('participant.dashboard')}</h1>
<p>{t('participant.teammatesDone', { selesai: 2, jumlah: 5 })}</p>
```

### Komponen pelayan (layout, generateMetadata)

```tsx
import { bahasaPelayan } from '@/lib/i18n/pelayan';
import { terjemah } from '@/lib/i18n';

const bahasa = bahasaPelayan();
const title = terjemah(bahasa, 'auth.loginTitle');
```

Jangan import `pelayan.ts` dari komponen klien: `cookies()` hanya wujud di
pelayan. Jangan import `BahasaProvider` dari komponen pelayan.

### Fungsi tulen dalam `src/lib`

Fungsi tulen (tiada React) menerima bahasa sebagai parameter terakhir yang
boleh diabaikan, lalai `'en'`, supaya ujian sedia ada tidak berubah:

```ts
labelTarikhQuest(endAt, sudahTamat, new Date(), bahasa);
```

## Menambah kunci

1. Tambah kunci dalam `kamus/en.ts` dahulu (sumber jenis).
2. Tambah padanan dalam `kamus/ms.ts`. Jika tertinggal, `tsc` gagal: itulah
   tujuannya.
3. Ganti rentetan keras dengan `t('ruang.nama.kunci')`.

Ruang nama sedia ada: `common`, `nav`, `auth`, `oauth`, `participant`,
`papan`, `ui`, `kelas`, `lna`, `banner`, `sijil`, `sertai`, `papanKelas`.
Tambah ruang nama baharu hanya bila satu blok halaman penuh memerlukannya.

## Jamak

Jamak ringkas guna dua kunci berakhir `_one` / `_other`, contoh dalam ruang
`kelas`:

```ts
// en.ts
studentOne: '{n} student',
studentOther: '{n} students',
```

Panggilan:

```ts
terjemahBilangan(bahasa, 'kelas.studentOne', 'kelas.studentOther', n, { n });
```

Pembantu memilih `_one` bila `n === 1`, selain itu `_other`.

## Interpolasi

`{nama}` diganti dengan nilai yang dihantar: `t('sertai.byEducator', {
pendidik: 'Dr Hariz' })`. Nilai disisip sebagai teks, bukan HTML; jangan
sesekali guna `dangerouslySetInnerHTML` untuk kandungan terjemahan.

## Kuki dan penyimpanan

`tukarBahasa` menulis `kz_lang` dengan `path=/`, `max-age` satu tahun dan
`SameSite=Lax`, menghantar salinan ke `localStorage`, kemudian
`router.refresh()`. Nilai kuki tidak dipercayai: `sahBahasa` hanya menerima
`en` / `ms`; apa-apa yang lain jatuh ke `en`.

## Tarikh dan nombor

Guna `Intl` dengan lokal dari `LOKAL[bahasa]` (`en-GB` atau `ms-MY`):

```ts
new Date(iso).toLocaleDateString(LOKAL[bahasa], { day: 'numeric', month: 'short' });
```

## Larangan

- Jangan mencampurkan dua bahasa dalam satu skrin.
- BM Malaysia baku: lajur bukan kolom, cekap bukan efisien. Tiada perkataan
  Indonesia.
- Tiada em dash (\u2014) dalam mana-mana nilai kamus atau teks UI.
- "Kuizen" ialah jenama: kekal "Kuizen" dalam kedua-dua bahasa.
- Kandungan pengguna (nama kelas, soalan kuiz, label Outcome, mesej sembang,
  jawapan AI) tidak pernah diterjemahkan.
- Halaman pemasaran/SEO (`/en`, root `/`, `panduan/**`, `blog`, `privacy`,
  `terms`, `help`) kandungan khusus bahasa; di luar sistem ini.
- Tiada kebergantungan npm baharu untuk i18n; sistem ini cukup dengan dua
  fail kamus dan satu fungsi carian.
